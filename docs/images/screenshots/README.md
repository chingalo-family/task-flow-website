This directory is prepared to host mobile app screenshots for the Task Flow website.

```

│       └── (same structure)
└── ios/
    ├── iphone/
    │   └── (same structure)
    └── ipad/
        └── (same structure)
```

## Adding Screenshots

1. Capture screenshots from the Task Flow app
2. Use the recommended screen sizes:
   - Android Phone: 1080x2400px or higher
   - iOS iPhone: 1170x2532px or 1284x2778px
   - Tablets: Appropriate sizes for respective platforms

3. Optimize images:
   - Format: PNG or JPEG
   - Target size: 200-500KB per image
   - Tools: TinyPNG, ImageOptim, Squoosh

4. Follow naming convention:
   - `login.png`
   - `home-dashboard.png`
   - `task-list.png`
   - etc.

5. Place in appropriate directory based on platform and device type

## Image Optimization Tools

- [TinyPNG](https://tinypng.com/)
- [ImageOptim](https://imageoptim.com/)
- [Squoosh](https://squoosh.app/)
