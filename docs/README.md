# Task Flow Website

This directory contains the Task Flow website hosted on GitHub Pages.

## Structure

```
docs/
├── index.html          # Main HTML file
├── css/
│   └── styles.css      # Main stylesheet
├── js/
│   └── main.js         # JavaScript functionality
├── images/
│   ├── icons/          # Favicon and other icons
│   └── screenshots/    # App screenshots
│       ├── android/
│       │   ├── phone/
│       │   └── tablet/
│       └── ios/
│           ├── iphone/
│           └── ipad/
├── robots.txt          # Search engine robots file
├── sitemap.xml         # XML sitemap
└── .nojekyll           # Disable Jekyll processing
```

## Features

- Fully responsive design (mobile, tablet, desktop)
- Dark theme matching the app's color scheme
- Smooth animations and transitions
- Accessibility compliant (WCAG 2.1 AA)
- SEO optimized with meta tags and Open Graph
- Cross-browser compatible

## Screenshots

To add screenshots:
1. Capture screenshots from the Task Flow mobile app
2. Optimize images (recommended size: 200-500KB)
3. Place them in the appropriate directory under `images/screenshots/`
4. Follow the naming convention: `screen-name.png`

## Deployment

This website is automatically deployed to GitHub Pages from the `docs` folder.

URL: https://chingalo-family.github.io/task-flow-website/
